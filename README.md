# 马克思主义基本原理在线刷题系统 (539题全收录)

本平台为**马克思主义基本原理（马原）**量身打造的高效刷题与期末/考研备考系统，完整收录并结构化校准了 **539 道** 权威全真题库。

系统采用现代化架构重构，兼备**零依赖双击即用（离线单文件 SPA）**与 **Python Flask RESTful Web 部署**双重运行模式，带来极致流畅、毫秒级响应的沉浸式刷题体验！

---

## 🌟 核心特色与功能亮点

### 1. 📖 智能刷题模式 (Practice / Study Mode)
- **多题型全覆盖**：
  - **单项选择题 (380题)**：选项清晰直观，点击即判，正确/错误高亮提示，答对支持**自动跳转下一题**（延时 380ms，支持自由开关）。
  - **多项选择题 (159题)**：复选勾选，一键“提交查看答案”，判定对错并高亮标示漏选与错选选项。
- **进度自动记忆**：支持 `localStorage` 本地自动保存，刷新页面或下次进入时提示“检测到上次刷题进度”，一键无缝续刷。
- **全景答题卡抽屉**：支持一览全部题号，已答/未答/正确/错误状态一目了然，支持输入题号直接跳转。
- **全键盘快捷键支持**（PC 端体验极佳）：
  - `←` / `→`：上一题 / 下一题
  - `A` / `B` / `C` / `D`：快捷选中对应选项
  - `Enter`：提交多选作答
  - `Esc`：关闭成绩单弹窗

### 2. 📝 模拟考试模式 (Mock Exam Mode)
- **多模式组卷方案**：
  - 🎯 **全真期末模拟卷**：科学配比（单选题 70 题 + 多选题 30 题，共 100 题，百分制标准模拟）。
  - 🎲 **随机抽考 50 题**：全库随机抽取（单选 35 题 + 多选 15 题），快速检测掌握程度。
  - 🎯 **专项攻坚**：单选题专项模考 (50题)、多选题专项攻坚 (30题)。
- **全真考试体验**：
  - 动态计时器（精确统计答题用时）。
  - 交卷未作答智能防漏答确认提醒。
  - 考后自动生成详尽**成绩分析单**（得分率、考核评级、耗时统计、逐题核对清单）。
  - 错题自动批量收录至错题本。

### 3. 📋 题库速览与考前背诵 (Browse & Memorize Mode)
- **全局毫秒级实时搜索**：输入任何关键词（如“唯物史观”、“生产力”、“剩余价值”、“实践”、“矛盾”），毫秒级检索匹配全部题目及选项答案，并自动高亮关键词！
- **考前背题模式（答案遮罩）**：一键开启“背题模式”，答案默认模糊遮挡，点击卡片即展开，考前突击背诵必备！
- **题型分类筛选**：全部 / 单选题 / 多选题 随心切换。

### 4. ❌ 错题本与高频错题归纳 (Wrong Book)
- 刷题与测试中答错的题目**自动收录**，并记录累计错误次数。
- 提供**🔁 错题专练**功能，一键提取所有错题进行针对性攻克。
- 掌握后支持单题移除或一键清空错题记录。

### 5. ⭐ 考点收藏夹 (Favorites)
- 遇到重点、难点、易混淆考点，随时点击右上角五角星加入收藏。
- 支持**⭐ 专练收藏题目**，复习更有靶向性。

## 🚀 运行方式（两种模式任选）

### 模式一：极简零依赖 · 双击即用（推荐）
本系统已将完整 539 题题库与前端单页应用全部内嵌于 `index.html`。
1. 直接用任意现代浏览器（Chrome、Edge、Safari、Firefox、手机浏览器等）双击打开根目录下的 **`index.html`**。
2. 无需安装 Python、无需配置任何环境、断网亦可秒开秒刷！
3. 也可直接将 `index.html` 部署到 GitHub Pages、Vercel 或任意静态服务器上。

### 模式二：Python Flask 后端服务
适合搭建局域网共享刷题、校园内网服务或云服务器独立部署：
1. **Windows 用户**：
   - 直接双击运行项目根目录下的 **`一键启动.bat`** 即可自动检测环境、安装依赖并启动！
2. **命令行启动**：
   ```bash
   # 安装依赖
   pip install -r requirements.txt

   # 启动后端 API 服务
   python webapp/app.py
   ```
3. 打开浏览器访问：👉 **`http://localhost:8080`**

## 🛠️ 后端 REST API 参考

| 接口地址 | 请求方式 | 参数说明 | 接口功能 |
| :--- | :---: | :--- | :--- |
| `/api/stats` | `GET` | 无 | 获取题库各题型统计数量 |
| `/api/questions` | `GET` | `mode` (all/single/multi), `shuffle` (0/1) | 获取刷题题目（已剔除答案） |
| `/api/browse` | `GET` | `mode` (all/single/multi) | 获取浏览题库数据（含参考答案） |
| `/api/test` | `GET` | `mode` (standard100/random50/single50/multi30), `count` | 组卷抽题接口 |
| `/api/check/<idx>` | `GET` | `idx` (题目全局索引) | 实时核对某道题的正确答案 |
| `/api/grade` | `POST` | JSON: `{"indices": [...], "answers": {"0": "A", ...}}` | 试卷批量提交与智能自动判分 |
